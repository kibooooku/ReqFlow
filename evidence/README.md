# 公开验证证据说明

本目录保留课程开发过程的初版、重设计前、第一轮修订和最终验证证据。最终摘要见 `final/verification.json`：50 项自动化测试通过，Python 语句覆盖 861/914（94.20%），Microsoft Edge 浏览器 16 步验收通过；启动依赖探测另行记录。旧版失败记录用于解释真实缺陷和修复过程，不代表最终版本验收失败。

## 脱敏范围

- 本机项目目录、工作区目录和用户目录分别替换为 `$PROJECT_ROOT`、`$WORKSPACE_ROOT`、`$USER_HOME`。
- JUnit XML 的 `hostname` 属性替换为 `REDACTED_HOST`。JSON/XML 序列化可能改变空白和实体转义格式。
- 未改动测试计数、成功/失败状态、断言、覆盖率、时间、浏览器步骤或截图。环境错误日志和历次 UI 失败记录也保留，只实施相同脱敏。
- 不包含任何运行数据库、SQLite 附属文件、会话数据、`.coverage` 原始数据库、虚拟环境或缓存。应用启动时自行生成教学数据；截图与 CSV 展示的身份、需求和账号来自教学 fixture 与验收脚本。

## 快照及复现

`initial/source.zip`、`before-redesign/source.zip`、`final/source.zip` 均只包含项目源码、测试、脚本和说明文件，按原始字节保留，未含个人目录、运行数据库或真实凭据。各目录的 `source-manifest.json` 用于校验相应归档中的文件；本次公开副本的 README、忽略规则及规划引用有适应性调整，因此不应使用历史快照清单校验当前仓库整个目录。

初版及重设计前快照是历史研究材料，其中包含已修复的问题。常规运行和重新验证应使用仓库根目录当前代码及 README 指令。这里不重复执行测试，也未把原有失败证据改写为成功。
